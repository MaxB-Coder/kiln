Checklist the app is held to

    

  1. Header pills. The header's left side shows the session name, dim ("api"). The right side shows the context as pills: project (orange #e07b39, dark text), git branch with a change count (#3c3836, "✱2" in orange; no count when clean; no pill outside a repo), and the runtime (#32302f, muted text, "node 25"), plus the WSL distribution on Windows. The runtime pill appears only when the project uses it (package.json or .nvmrc for Node, Cargo.toml or rust-toolchain.toml for Rust, go.mod for Go, pyproject.toml or .python-version for Python), never in Home or plain folders. Drawn by Kiln, the same on every OS and shell; nothing is repeated in the input box.
    2. 

  2. Flame prompt. The input box (#32302f, radius 10, inset) holds only a small flame and what you type: no pills, no runtime text. The flame is four vector frames (assets/flame/flame-1..4.svg) swapped every 150 ms in order, a stop-motion flicker. Accent orange when ready; muted red (#b8645a outer, #d0927f inner) after a failed command; it holds still on frame 1 when the window isn't focused or the OS asks for reduced motion. Only the flame's area redraws.
    3. 

  3. Focus mode (⌘.). Sidebar and rail fold away; timeline and input box narrow to reading width (about 72% of the window, centred, capped near 100 columns); the header's right side shows how many things are running, before the pills.
    4. 

  4. Select commands from the keyboard (⌘↑ / ⌘↓; Ctrl+Shift+↑/↓ elsewhere). Moves a selection between commands (hover background #2f2d2c and its actions shown), scrolling it into view. ⌘C or Enter copies it (paste-ready), Esc clears.
    5. 

  5. Several commands at once. ⇧-click (and ⇧⌘↑/↓) extends the selection; Copy then puts all of them in one paste-ready block, in order.
    6. 

  6. Copy confirmation. Every copy shows a small note above the input box for about 2.5 s: "⧉ Copied, ready to paste" (or "Copied raw output") with the first lines of what was copied, dim. Panel #1d2021, ring #504945, radius 10.
    7. 

  7. Pinned commands stay in view. Pinned blocks sit at the top of the timeline (header plus a few lines, quiet grey dot, "pinned · time"), visible while you work and scroll; click to expand; unpin from the hover actions.
    8. 

  8. Find (⌘F). A bar across the top of the timeline (#32302f, radius 8): "⌕ query" on the left, "2 of 5 · ⏎ next · ⇧⏎ previous · esc" dim on the right; matches highlighted in place.
    9. 

  9. Palette (⌘K). Results under quiet group headings (Commands, Projects, Sessions, Actions), dim detail on the right (shortcut, folder, "rerun · project"); no per-row type tags.
    10. 

  10. Sidebar hint. A dim "⌘K" (Ctrl+Shift+K) at the bottom of the sidebar; clicking it opens the palette.
    11. 

  11. Shortcuts pop-up (⌘/). Every shortcut, grouped, as key caps, filterable, built from the real key bindings.
    12. 


Unchanged from what is built: the sidebar (projects with colour dots, sessions, Home group, muted status dots), command blocks with hover actions, split panes each with their own input box, the ⌘I rail, paste-ready copy format, notifications, SSH and production tints, Windows window controls and the >_ mark.
